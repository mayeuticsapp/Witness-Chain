Riguardo al database Neon e ai file multimediali - No, i file multimediali NON vengono salvati nel database. Nel database viene salvato solo il riferimento al file (fileUrl), non il file stesso. I file vengono salvati sul filesystem locale nella cartella uploads. Per Render, questo è un problema perché Render usa un filesystem effimero - i file vengono cancellati ad ogni deploy.
Per risolvere questo problema, l'utente dovrà usare un servizio di object storage come:
* AWS S3
* Cloudflare R2
* Backblaze B2
* etc.

Riguardo alla verifica: OpenTimestamps usa la blockchain Bitcoin per ancorare i timestamp. Ci vogliono circa 1-2 ore perché il timestamp venga confermato sulla blockchain. Finché non è confermato, la verifica potrebbe non funzionare completamente. È normale.

Riguardo ai file multimediali e Neon:
⚠️ IMPORTANTE: I file multimediali NON vengono salvati nel database! Nel database viene salvato solo:
* Il riferimento al file (fileUrl)
* L'hash del contenuto (contentHash)
* I metadati
I file veri e propri vengono salvati nella cartella uploads/ sul filesystem.
Problema per Render: Render ha un filesystem "effimero" - i file caricati vengono cancellati ad ogni deploy!

Soluzioni per i file multimediali:
1. Cloudflare R2 (consigliato, gratis fino a 10GB)
2. AWS S3
3. Backblaze B2 (economico)
